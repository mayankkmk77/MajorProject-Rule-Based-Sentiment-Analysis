## 📌 Project Overview

This project performs **Rule-Based Sentiment Analysis** on customer reviews collected from e-commerce platforms.

Instead of using machine learning models, the system applies **Natural Language Processing (NLP)** techniques and predefined sentiment rules to classify reviews as:

- 😊 Positive
- 😐 Neutral
- 😞 Negative

The project demonstrates how customer feedback can be analyzed efficiently using a lightweight and interpretable rule-based approach.

---

# 🎯 Objectives

- Analyze customer reviews.
- Perform text preprocessing.
- Detect positive and negative sentiment.
- Calculate sentiment scores.
- Display analytical insights.
- Store review data in MySQL.
- Visualize results using charts.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mayankkmk77/MajorProject-Rule-Based-Sentiment-Analysis.git
```

Move into the project folder

```bash
cd MajorProject-Rule-Based-Sentiment-Analysis
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Flask server

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
